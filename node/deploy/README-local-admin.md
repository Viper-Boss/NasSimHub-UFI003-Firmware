# 独立设备后台首次设置

管理服务运行在棒子自身的 HTTPS 7581 端口，不依赖 NAS 保持在线。管理密码与 NAS 登录密码、Node 配对身份互相独立。

## 已经配对 NAS

在 NAS 的 SIM 节点页找到本机设备，点「打开棒子后台」。NAS 使用已配对、固定设备公钥的加密连接确认所有权，打开本机后台后只需输入至少 12 位密码和确认密码。此入口不会代替你设置密码，也不会让 NAS 获得管理密码。

首次进入时，请由本人核对设备地址并处理本机证书提示。设置成功后，直接使用设备的 https://设备地址:7581/ 与独立管理密码登录。

初始化证明仅通过链接片段传递，页面载入立即清除，不存入浏览器持久存储、普通节点列表或日志。完成首次设置后证明销毁。只有 NAS 管理员可以生成入口；未配对、已撤销或离线设备不能生成。

## 设备未配对 NAS

可信本机维护环境可以运行 New-AdminSetupLink.ps1，从预先验证的 SSH 维护连接读取本机一次性初始化证明并生成私有设置快捷方式。请勿分发该快捷方式或维护私钥。高级维护也可填写本机初始化码。

直接打开没有初始化证明的普通地址时，页面显示入口指引；设置按钮旁会提示缺少证明、密码不足 12 位或确认不一致。无需在公共发布包内附带任何固定初始密码。

## 实现与边界

NAS POST /api/v1/nodes/admin 继承管理员和 CSRF 检查；Node POST /v1/admin/access 要求已配对 Core 的认证会话和 TLS。独立后台不接受 Core 身份替代管理密码，也不会向普通浏览器暴露初始化证明。

支持设备概览（CPU/内存/存储、蜂窝状态、进程）、Wi-Fi、短信、安全、更新、诊断与修改管理密码，页面一览见下文。通话和数据转发由 NAS 负责；此后台没有刷机、格式化、NV 修改或恢复出厂按钮，也没有对应的接口。

## 会话与登录保护

以下数值是代码中的常量（agent/internal/localadmin/admin.go），不可通过配置放宽。

- 会话只存在于 Agent 内存中，Agent 重启后所有浏览器需要重新登录。Cookie 名为 __Host-nsh-admin，带 Secure、HttpOnly、SameSite=Strict，路径为 /。
- 闲置 30 分钟自动失效。只有人为操作才会续期；页面自身的定时刷新带有 X-NSH-Passive 标记，不计入活动，所以放着不管的标签页不会一直保持登录。
- 无论是否活跃，登录满 12 小时后必须重新登录。
- 最多同时保留 32 个会话，超过时淘汰最久未使用的一个。
- 退出登录立即在设备端作废会话；修改管理密码会作废包括当前在内的全部会话，并只为发起修改的浏览器签发新会话。
- 所有改变状态的请求都必须同源并携带 X-CSRF-Token，唯一的例外是登录本身（此时还没有令牌，由同源检查、SameSite 和下面的锁定保护）。
- 连续输错 5 次管理密码（或初始化码、修改密码时的原密码、查看配网热点口令时再次输入的管理密码）后锁定 1 分钟，此后每多错一次锁定时间翻倍：2、4、8 分钟，上限 15 分钟。锁定期间不再校验密码，直接返回 429 和 Retry-After。登录成功后计数清零；锁定结束后再安静 15 分钟也会清零。锁定是全设备范围的，不区分来源地址：有人在局域网里反复猜密码时，你自己也要等锁定结束。
- 管理密码以 PBKDF2-HMAC-SHA256（210000 轮、24 字节随机盐）的结果保存在 admin.json，权限 0600；设备上没有明文密码。
- 会话过期或退出后，页面会清空已显示的设备数据、短信和日志，并提示「会话已过期，请重新登录」。

登录失败、锁定、修改密码、回滚更新，以及查看配网热点口令（成功或被拒绝）会写入设备日志（来源 admin），日志里不含密码、初始化码、会话令牌或热点口令。

## 页面一览

- 设备概览：CPU、内存、存储、蜂窝注册与信号、SIM 状态、进程和接口流量，以及「系统遥测」：
  - 处理器型号、核心数、1/5/15 分钟负载均值（运行队列均值，不是百分比），每个核心的在线状态、当前/最低/最高频率和利用率；
  - 每一个温度区，标签用内核自己给出的类型（type）；没有类型的温度区标为「类型未知」，页面不会自行把某个温度区叫作 CPU；
  - 内存明细（总量、可用、空闲、缓冲区、页缓存、交换区）、状态目录和根文件系统的容量；
  - eMMC 寿命寄存器的原始值及其含义：寿命估计 0x01 表示已用额定寿命的 0–10%，每加 1 再多 10%（0x0A 为 90–100%，0x0B 为已超过额定寿命，0x00 为设备未上报）；预留块状态 0x01 正常、0x02 警告、0x03 紧急。这是厂商的估计值，页面不把它换算成设备没有给出的百分比；
  - 每个网络接口的收发速率、累计字节、包数和错误数。速率 0 B/s 是真实测量值（这一段时间没有流量）；设备没有给出速率时显示「未知」；
  - Agent 进程自身的 PID、常驻内存和 CPU 占用；服务小区的频段、EARFCN、PCI、TAC、Cell ID，带它自己的采样时间（可能早于页面其他数据）。
  设备没有上报的项目一律显示「未知」，不显示 0，也不沿用之前的数值。遥测随原有的状态轮询（10 秒，仅在概览页可见时）一起读取，没有额外的定时请求。设备一时没有应答时，页面保留上一次的数据并注明「不是当前状态」。
- 无线网络：扫描、连接、忘记已保存网络。SSID 最多 32 字节（一个汉字占 3 字节）；WPA2/WPA3 密码 8 至 63 位，WPA2 也可填 64 位十六进制密钥。另外显示：
  - 配网状态（`provisioning_state`）及原因，用文字说明：尚未配置、正在启动热点、热点已启动、热点启动失败（附原因，USB 不受影响）、正在加入、已连上、加入失败正在恢复、已保存的网络暂时连不上、已保存的网络持续连不上即将提供热点、以及「配网热点已关闭：通过 USB 配置 Wi-Fi」。设备没有给出状态时显示「未知」。
  - 扫描结果的支持标记：「此类网络已验证过」「未验证：可能可用，也可能不可用」（例如 5 GHz、纯 WPA3）和「不支持」（企业级 802.1X），后面附设备给出的原因。任何网络都不会被隐藏，页面也不承诺某个网络一定能连上；不支持的网络照常列出，只是不能点选。
  - 扫描结果来自缓存时（射频正在提供热点、无法重新扫描）会注明，并显示那次扫描的时间。
- 配网热点（在「无线网络」页内）：显示热点名称（SSID）和热点状态。热点口令默认不显示，点击「显示口令」后必须再次输入管理密码，由设备端校验；输错计入上面的登录锁定。详见下文「配网热点口令」。
- 短信管理：查看、发送、删除棒子上的短信。收件号码为 3 至 20 位数字，可以 + 开头；内容最多 4096 字节。每次发送带一个请求编号，设备超时未答复时页面不会自动重发；内容不变时再次手动点击发送会沿用同一编号，由设备判断是否已经发过。
- 安全（只读）：设备 ID 与 Ed25519 公钥指纹、安全等级（STANDARD / PQ / PQ_EXTREME）、后量子身份状态（已启用 / 此版本不支持 / 已关闭 / 密钥损坏）及其算法和指纹、配对的 NAS（Core ID、指纹、是否已固定其后量子密钥）、本后台 HTTPS 证书的 SHA-256 指纹和到期时间。只显示公开指纹，不显示任何密钥；没有依据的项目显示为「未知」。设备指纹的格式与 NAS 上显示的一致，可以逐位核对。
- 更新：运行版本、出厂版本、当前发布、状态、目标版本、传输进度、确认期限、最近错误和重启原因、是否支持更新及原因、签名策略和发布密钥数量。唯一的操作是回滚「已应用但尚未确认」的更新，执行前会再次确认，随后 Agent 重启、页面断开。没有更新服务的版本显示「此版本没有更新服务」，这不是故障。
- 诊断日志：最近日志和诊断包下载。日志写入时已脱敏，诊断包不含管理密码、会话令牌、Wi-Fi 密码、短信内容、完整号码、ICCID/IMSI 或设备私钥。
- 管理设置：修改管理密码、设备与软件信息。

## 修改 Wi-Fi 时会发生什么

USB 管理地址 https://10.55.0.2:7581 不经过 Wi-Fi，修改 Wi-Fi 不会影响它；页面在提交前会说明这一点。

已保存的网络只有在新网络连接成功之后才会被替换。新网络最长约 90 秒内连不上时，新配置被丢弃，原配置原样保留。设备上已有保存的网络时，切换失败后设备回到已保存的网络，而不是回到配网热点；只有在没有已保存的网络时才回到配网热点（且热点没有在配置中关闭）。如果已保存的网络此时也连不上，它仍然保留在设备上：设备继续等它恢复，或在保留它的同时重新提供热点，「无线网络」页的配网状态会写明是哪一种。页面在提交前会说明这一点。提交后页面会持续读取设备的实际状态（最长约 3 分钟），并如实告诉你结果：已连上新网络、已回到原来的网络、已回到配网热点、仍未连接，或无法确认。页面不会把「没有消息」当成「成功」。

如果你是通过 Wi-Fi 地址访问后台的，切换网络后设备地址可能改变，页面会提示改用新地址或 USB 地址。

## 配网热点口令

配网热点（`provisioning_ap = auto` 时由设备提供，WPA2，口令由设备自己生成、每台不同）的口令是一个凭据：知道它的人站在设备附近就能打开配网页面。因此：

- 只有已登录本后台的会话才能看到「配网热点」这一栏；口令本身只在点击「显示口令」并再次输入管理密码后返回一次。校验在设备端完成，输错与登录输错共用同一个锁定计数。
- 对应的请求（`POST /admin/api/v1/wifi/setup-ap/reveal`）与其他改变状态的请求一样，必须同源、带会话 Cookie 和 X-CSRF-Token；应答带 `Cache-Control: no-store`。首次设置阶段（还没有管理密码）没有会话，无法访问它；初始化证明不能代替管理密码。
- 口令不写入日志（日志只记录「已显示」或「被拒绝」这件事）、不出现在 Wi-Fi 状态、诊断文档或诊断包里，也不保存在浏览器。点击「隐藏口令」、离开无线网络页、退出登录、会话过期或显示满 180 秒后，口令从页面清除。
- 设备的 Wi-Fi 后端没有带口令的热点时，这一栏写明「没有可显示的口令」；热点在配置中关闭（`provisioning_ap = off`）时写明「配网热点已关闭：通过 USB 配置 Wi-Fi」，此时设备也不会为它生成口令。

内置默认和随包配置的 `provisioning_ap` 目前都是 `off`：热点还没有在真机上验收。在这种配置下，这一栏显示的就是「已关闭」。本节描述的行为只在离线测试里验证过。

## 只能在 NAS 上做的事

- 配对、解除配对、更换配对的 NAS。
- 更新的获取、上传、应用和确认。本后台只能查看状态和回滚未确认的更新，不能上传任何文件。
- 通话、通话音频和数据转发。
- 传输密钥轮换和安全等级的更改（安全等级来自设备配置文件，本后台只显示）。

## 短信发送被使用策略拒绝时

短信卡片会按设备返回的状态解释原因，并给出恢复方法：设备重启后等待已配对 NAS 重新确认、策略过期、观察期只接收不外发，或设备已被限制/隔离。损坏的策略也会明确提示需由 NAS 修复。观察期和限制不会因重新连接 NAS 自动解除；管理密码不能解除使用策略。

被拒绝后，收件号码和内容草稿保留，页面不自动重试。“重新检查”只查询设备策略，不发送短信；NAS 确认恢复后，用户需要自己再次点击“发送短信”。查询失败或返回未知状态时，页面保留原提示，不把未知当成恢复。发送是否允许最终由设备端判定，页面提示不能代替信任闸门。

本段说明对应 r129-small。真实浏览器的弹窗/焦点流程及设备重启后与 NAS 的恢复流程仍需现场验收；离线测试通过不代表真机流程已通过。
