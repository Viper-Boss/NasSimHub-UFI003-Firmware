# 开发路线与验收

## 优先完成

- 浏览器真实双向电话：拨出、接听、挂断、来电、对端先挂、USB 中断与 Agent 重启；以真实状态与媒体帧验收，不能只看网页按钮。
- 多棒子 USB 隔离、发现与逐设备卡片数据；回归宿主 QDC507，禁止命令误发到另一设备。
- 干净 Factory Image / OTA。**源码已完成、离线测试通过**：可复现构建、Factory 包（Lite/Dev）、Agent OTA（Ed25519 + 可选 ML-DSA 双签、仓库外签名、设备侧校验、确认窗口、自动回滚、Factory 版本下限）、SBOM 与通用性检查。**未在真机验证、仍待完成**：实际刷机报告、真实设备上的升级/确认/回滚/断电恢复、持久身份在刷机前后保留、密钥轮换、板型锁定；系统镜像级 OTA（内核、rootfs、基带）尚未实现。
- 配网热点。**源码已完成、离线测试通过**：状态机与 NetworkManager 后端（Node 侧），镜像侧前置条件作为可选片段（`NSH_SETUP_AP=on`，默认关闭）。**未在真机验证、仍待完成**：热点在本板上能否启动、手机能否拿到地址并打开配网页面、口令的界面展示（目前只能经 USB 读文件）。Windows 配置客户端通用设备配置、后台初始化与证书导引仍待完成。
- 4G 频段/PCI/EARFCN/TAC/小区号已按真实 QMI 来源上报（来源是通话部署里的定时器，通用镜像不带，见已知问题）；服务小区带宽**没有**上报：需要再加一条 QMI 查询，这一轮有意没加。不伪造未知值。
- 设备遥测（温度区、CPU 频率、eMMC 寿命、网卡计数）已有采样代码与离线测试；各数据源在本板上是否存在、在服务沙箱内是否可读，待按 VALIDATION.md 验收。
- 短信、通话统计时间单位和逐线路归属，持续运行及重新接入回归。

## 协议方向

- 已有 TLS 1.3、Ed25519 证书绑定与配对认证；继续完善安全姿态可观测性。
- 按工具链支持验证混合后量子密钥交换。ML-DSA 设备身份、双签 OTA、PQ_EXTREME 下拒绝非双签发布均已实现并有离线测试；它们的真机验收尚未进行。
- Node 本地的信任策略（观察期、风险状态）只有独立的状态机代码，没有接入任何请求路径；目前信任由 NAS 执行。
- 可选 KCP/FEC 代码需在真实弱网设备回归。QUIC 尚未实现。
- NAS 的浏览器 Opus/WebRTC 媒体完整互通；未来可研究标准 SIP/SRTP 与现成手机客户端桥接，目前不宣称 CallKit 或 SIP 客户端可直接连棒子。
- DTMF、其他运营商/基带组合与纯 WPA3 作为后续验证项；EVS 不在当前实现范围。

每项功能通过后应提交测试环境、板型、版本、结果及限制；不包含电话号码、SIM 标识、运营商秘密、密码或私人录音。
