# Contributing

Run scripts/check.sh and scripts/build-agent.sh before submitting changes. Preserve protocol contracts and yes/no/unknown capabilities. Keep hardware-specific changes separate from generic identity/transport behavior. Add tests for failure and cleanup paths rather than assuming hardware capability.

Contributions to project-owned application code are under AGPL-3.0-only. Contributions to Linux-derived kernel/audio files retain the file's existing GPL/SPDX license. Do not contribute proprietary modem binaries, carrier profiles, personal data or code you lack permission to publish. Include hardware testing scope and limitations in pull requests.
