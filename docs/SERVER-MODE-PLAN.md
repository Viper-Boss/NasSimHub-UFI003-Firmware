# 独立服务器模式：账户与 SSH 管理

状态：2026-10-08 第一优先级的账户与 SSH 管理已实现并部署 dev46；真机普通用户创建、公钥登录、sudo 授予/撤销、锁定/解锁、SSH 开关和保留家目录删除已通过。网页使用模拟 DOM 验证，真实浏览器视觉与管理员操作待用户验收。后续项仍按下文处理。详见 SYSTEM-ADMIN.md。

## 当前确认

- 独立后台管理密码与 Linux 系统账户无关；现在通过“系统管理”可管理普通账户、root 密码和公钥，以及独立通用 SSH。
- Agent 使用 nassimhub 服务账户，启用了 NoNewPrivileges；不能直接执行 sudo、useradd 或 chpasswd。不能靠把网页 Agent 改成 root 实现这些功能。
- 当前真机已补齐 openssh-client 和 sudo，沿用现有 OpenSSH server；量产镜像依赖仍待刷机包恢复时加入和锁定。私人维护 SSH 与通用 SSH 分开，不将维护密钥带入公开固件。
- 当前设备的通话、收短信已经由用户实测确认正常。通话媒体仍是 16 kHz PCM，不能据此断言网络使用高清编码。
- 旧的 KNOWN_ISSUES、FIRST_BOOT 等文档有滞后描述，需要与实际构建锁、运行版本和验收结果统一。

## 第一优先级：系统用户、root 与 SSH

独立后台增加“系统管理”页，沿用现有卡片、表单、焦点和错误提示。

### 账户

1. 网页管理员、普通 Linux 用户、root 分别管理；后台密码不能自动成为 SSH/root 密码。
2. 支持创建普通用户、修改密码、上传与移除 SSH 公钥、锁定/解锁；显示 UID、主目录、登录方式与 sudo 权限。
3. sudo 授权必须单独操作；不提供所有用户默认免密 sudo。
4. root 支持修改本机密码、管理公钥与单独的远程登录策略；禁止共享默认密码。SSH root 默认禁用，开启时默认只用公钥。
5. nassimhub、系统服务用户、UID 小于 1000 的内置用户不能通过普通用户删除操作修改。用户删除与删除主目录分开，主目录不自动清除。
6. 密码不能进入命令行、日志、诊断包或响应；公钥需要解析格式、算法、长度，拒绝 authorized_keys 命令选项及换行注入。
7. 每台设备独立生成 SSH 主机密钥，保存与恢复只用于本设备，不复制首台设备的账户、密码哈希或主机密钥。

### SSH

1. 通用 SSH 默认关闭；默认独立端口 2222，避免覆盖当前私人维护通道。网页显示实际运行状态、端口、USB/Wi-Fi 地址和主机公钥指纹。
2. 支持开关、端口修改、公钥登录与普通用户密码登录开关；root 登录另有开关。
3. 配置先运行 sshd -t 检查，再原子写入和 reload；失败恢复前一配置。端口占用、缺失软件包必须给出具体错误。
4. 明确区分“服务正在运行”“开机自启”和“网络是否能访问”，不能把保存设置等同于可连接。
5. 开关通用 SSH 不得重启 Agent、ModemManager、语音进程，不得断开正在进行的电话。
6. 当前维护 SSH 不在此开关的控制范围；界面如实说明两者的区别。

### 权限边界

- 用独立 root 管理服务监听本机 Unix socket，文件权限限定服务账户；校验 SO_PEERCRED。
- 只接受列出的操作与严格字段，不提供任意命令、脚本或文件路径接口；调用固定绝对路径程序，不使用 shell 拼接。
- 独立后台现有登录、CSRF、来源校验、会话失效和限速保护覆盖全部新路由。高权限操作需要当前管理密码再次验证。
- 管理服务只有需要的文件写入与能力；网页 Agent 继续普通用户运行。
- 不将“安装本机程序”的 root 能力等同于取得 NAS 其他成员数据的权限。

## 第二优先级：长期当服务器使用

- CPU、内存、存储、水位和温度提示，准确显示实际可用资源。
- 第三方程序使用独立 Linux 用户与 systemd 单元，配置 MemoryMax、CPUWeight、TasksMax；通信服务有优先级和保留空间。
- 日志轮转和磁盘写满保护，程序异常不得通过重启整个系统来恢复。
- 重启后用户、公钥、SSH 策略、程序数据保持；rootfs 更新前逐台备份，明确哪些数据会被保留。
- 最小诊断导出：系统版本、服务状态、错误分类，排除密码、私钥、短信内容、SIM 标识及 Wi-Fi 密码。
- rootfs 安全更新与回退、发布公钥、完整依赖锁和对应源码交付。

## 第三优先级

- LED 的状态定义与开关：启动、未配对、网络注册、通信活动与错误分开；夜间可关闭，禁止用不断重启基带驱动灯。
- USB/Wi-Fi 切换、断网恢复、拔插和长期运行验收。
- 首次设置后台密码不依赖 NAS，须由设备本地所有权证明保护，不能开放成任意网络访问者抢先设密码。
- 更新与安全模块中的未接线能力逐项核实，不把仅离线测试标成已可用。

## 上线验收

至少覆盖：未登录/CSRF 错误不能操作；命令与路径注入被拒；服务用户不能被改；密码与私钥不泄漏；创建用户和真实 SSH 登录；sudo 权限变化；root 禁用/公钥登录；无效配置回退；端口冲突；重启保持；通话中改 SSH 不影响媒体；SSH 关闭后通用入口不可达、私人维护入口保留；第二台设备的身份与主机密钥不同。

## 100 台刷机前

刷机包工作按用户要求暂缓。完成上述核心管理功能后先用一台试验、再用第二台检查首启隔离，最后再生成批量包。必须保留每台自己的固件、校准、NV 与恢复资料；不复制当前这台设备的私有 rootfs，也不凭“相同型号”跳过分区表核验。
