# r138 单设备真机验证

Debian 13 arm64、内核 `6.12.49-msm8916-g93a71ee9468d` 的修正候选系统在一台 UFI003 上通过 EDL 写入系统分区。没有改写 NV、校准、GPT 或持久身份分区。本人固件和维护配置仅在私有验收镜像内恢复，不随公共源码或通用包发布。

已完成：

- 冷启动和正常重启，USB 网卡、Wi-Fi 客户端、两个 remoteproc 和声卡恢复。
- 维护公钥登录、设备身份摘要保持、时间同步、NAS 公钥固定及签名会话。
- 12 条现有短信正文的 UTF-8 与转义检查，无乱码；重启后的正常空列表查询。
- 拨打运营商服务号码，真实呼叫进入 active，MDM2 媒体启动并收到 300 帧非静音 PCM；再次拨出时主动挂断成功，无剩余活动呼叫。
- 修正版 Agent `0.1.0-dev43` 安装前备份并设置回退定时器，认证与通话验收通过后取消回退。

此次修正包括固件目标目录创建、离线 radio 启动时序、USB gadget 管理、时间同步依赖，以及 ModemManager 空短信列表的标量形式兼容。源码全量检查与硬件验收分开记录，离线测试通过不替代真实通话。

16 kHz PCM 是 Linux 媒体格式，不能据此宣称网络使用 AMR-WB 或 EVS。新系统上的真实浏览器双向通话、来电、短信发送、配网热点和长期运行仍待验收；其他板型及运营商没有因这一台设备通过而自动获得支持。

r134/r135 旧候选包不等于 r138 验收系统。公开发布前须重建干净包、更新完整依赖锁并重复启动验收；私有镜像禁止公开。
