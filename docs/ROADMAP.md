# 开发路线与验收

## 优先完成

- 浏览器真实双向电话：拨出、接听、挂断、来电、对端先挂、USB 中断与 Agent 重启；以真实状态与媒体帧验收，不能只看网页按钮。
- 多棒子 USB 隔离、发现与逐设备卡片数据；回归宿主 QDC507，禁止命令误发到另一设备。
- 干净 Factory Image / OTA：板型锁定、持久身份保留、断电恢复、升级回滚、签名与来源核验；建立可复现构建和实际刷机报告。
- 首次 AP 配网、Windows 配置客户端通用设备配置、后台初始化与证书导引。
- 4G 频段/PCI/EARFCN/带宽等缺失字段按真实 QMI 来源补齐；不伪造未知值。
- 短信、通话统计时间单位和逐线路归属，持续运行及重新接入回归。

## 协议方向

- 已有 TLS 1.3、Ed25519 证书绑定与配对认证；继续完善安全姿态可观测性。
- 按工具链支持验证混合后量子密钥交换；完整 ML-DSA 身份、双签 OTA、PQ_EXTREME 发布验收尚未完成。
- 可选 KCP/FEC 代码需在真实弱网设备回归。QUIC 尚未实现。
- NAS 的浏览器 Opus/WebRTC 媒体完整互通；未来可研究标准 SIP/SRTP 与现成手机客户端桥接，目前不宣称 CallKit 或 SIP 客户端可直接连棒子。
- DTMF、其他运营商/基带组合与纯 WPA3 作为后续验证项；EVS 不在当前实现范围。

每项功能通过后应提交测试环境、板型、版本、结果及限制；不包含电话号码、SIM 标识、运营商秘密、密码或私人录音。
